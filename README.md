# 课件总结（courseware-summary）

## 解决什么问题

复习课件时，常常需要在定义、公式、算例和原图之间来回翻页。这个 Agent Skill 把一份或多份 PDF / PowerPoint 课件整理成一个可离线打开的复习网页。你可以按主题阅读讲解、快速查找公式，也可以从正文的页码直接打开原页核对。

总结以本次提供的课件为范围。它可以用课件自己的数据补全算例的计算步骤，并注明课件只列了标题或缺少数据的地方。

## 主要功能

| 功能 | 网页中的表现 |
| --- | --- |
| 逐页阅读与分节总结 | 按课件顺序归并主题，解释定义、公式、图表、代码和算例。每节末尾有带页码的复习要点。 |
| 原页对照 | 阅读时显示对应原页的缩略图。点击页码或缩略图可放大、翻页，并从放大视图返回正文对应位置。 |
| 速查 | 在同一个网页中按节汇总值得回查的定义、公式、规则、结论或步骤，支持按类型和关键词筛选，并跳回正文。 |
| 核对与勘误 | 复核关键数字和算例，在可运行时核对代码输出。有明确依据的错误会标出所在页、修正结果和对结论的影响。 |
| 多份课件与长课件 | 多份课件可在同一网页中切换或跳转。多份课件或节数较多时提供站内搜索和手动标记的复习进度，进度保存在当前浏览器。 |
| 公式与交互演示 | 渲染正文公式。遇到适合交互呈现的计算过程或参数关系时，可加入分步或参数演示。 |

## 安装方法

项目的 Skill 定义在 [`SKILL.md`](SKILL.md) 中。安装时只需复制该文件。生成阶段由宿主 Agent 读取课件并生成网页，运行环境需要能访问输入文件、查看或渲染课件页图，以及写入 HTML 文件。PowerPoint 的页图转换取决于宿主可用的工具。成品在浏览器里离线打开。

以 Codex 为例，下载或克隆本项目，然后将 `SKILL.md` 复制到下列任一位置。

| 使用范围 | 文件位置 |
| --- | --- |
| 当前项目 | `.agents/skills/courseware-summary/SKILL.md`（相对于使用 Codex 的项目目录） |
| 当前用户 | `~/.agents/skills/courseware-summary/SKILL.md`（Windows 的 `~` 对应用户主目录） |

如果目录还不存在，先创建它。复制后可在 Codex 中用 `$courseware-summary` 调用。若技能未显示，重启 Codex 后再试。 [Codex Skills 官方文档](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)

## 使用方法

1. 将一份或多份 PDF / PowerPoint 课件作为附件提供，或将它们放在宿主可读取的工作区内并在请求中写明路径。
2. 在对话中输入 `$courseware-summary` 并说明要总结哪些课件。也可直接提出“总结这份课件”或“把这几份课件做成复习网页”。默认用中文解释并保留便于对照的英文术语，也可指定输出语言。
3. 生成后，用浏览器双击打开交付的 `.html` 文件。原页图片、样式、脚本和公式渲染资源都内联在这个文件里。

若要把新课件并入已有的复习网页，同时提供新增课件和原 HTML，并说明要合并。Skill 会沿用已有网页的结构和风格。

## 输入输出示例

以下示例展示预期输出。课件文件名和内容仅用于演示。

**输入文件** `统计学-第03讲-算术平均数.pdf`

假设课件第 2 页给出算术平均数的公式，第 3 页列出数据 `2、4、6` 和结果 `4`。

**对话请求**

```text
$courseware-summary 总结《统计学-第03讲-算术平均数.pdf》，输出一个可离线打开的中文复习网页。
```

**输出示例** `统计学-第03讲-算术平均数-复习.html`

- 正文解释第 2 页公式中的符号，并用第 3 页的数据展示计算过程：先求和得到 `12`，再除以数据个数 `3`，得到平均数 `4`。
- 点击算例旁的 `p3` 标签可放大查看对应课件页，并返回算例所在位置。
- “速查”中的“算术平均数”条目显示公式和 `p2` 标签，也可以跳回正文中的公式讲解。
